# BuildArena Kaggle Final Entries

This repository contains the public supporting materials for two separate BuildArena S01 `Build with Agent / Autopilot` entries:

- `ENTRY_3P`: `MinimumCostOrbitalOpposedPair` — the 3-block primary entry.
- `ENTRY_5P`: `Minimal Orbital Thrustcraft` — the 5-block entry retained as a distinct performance–cost candidate.

Both machines were constructed through the BuildArena 2.0 MCP in Codex Desktop using GPT-5.6 Luna, then manually piloted after legal non-geometric tuning. The full writeups and chat/build transcripts are included with each entry.
